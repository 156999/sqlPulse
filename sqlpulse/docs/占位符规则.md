# SQL Pulse 压测占位符规则（V1）

实现：`app/services/sql_params.py`；Locust 执行入口：`app/locust_tpl/sql_user.py.j2`。

## 函数与类型

| 函数 | 规则 | 返回类型 |
|---|---|---|
| `rand(a,b)` | 整数闭区间，支持负数，a ≤ b | 整数 |
| `randf(min,max[,digits])` | 默认 2 位，精度为 0～10 的整数；按十进制网格均匀采样，不越界 | Decimal 定点小数 |
| `pick(值,...)` | 至少一个候选，均匀采样 | 保留候选类型 |
| `pickw((值,权重),...)` | 元组参数；权重有限、非负，合计有限且大于零 | 保留候选类型 |
| `randstr(n)` | 1～4096 位小写字母和数字 | 字符串 |
| `randdate('YYYY-MM-DD','YYYY-MM-DD')` | 严格格式、有效日期、闭区间 | 日期 |
| `randdt('YYYY-MM-DD HH:MM:SS','YYYY-MM-DD HH:MM:SS')` | 严格格式、闭区间、秒精度，无时区转换 | 日期时间 |
| `uuid()` | UUID v4 | 字符串 |
| `var('名称')` | 引用已配置的任务变量 | 保留变量类型 |

使用 `{{函数(参数)}}`。函数名区分大小写，参数使用 Python 字面量，不执行表达式或任意代码。
`pick`、`pickw` 候选仅允许字符串、有限数字、布尔值和 `None`；不接受列表、字典或嵌套结构。
`None` 绑定为 SQL `NULL`，布尔值绑定为 1 / 0。判断空值应使用 `IS NULL`，不要使用 `= NULL`。

`randf(0.001,0.009,2)` 没有满足精度的值，拒绝启动；`randf(0.001,0.019,2)` 只能生成 0.01。

## SQL 值与引号

```sql
SELECT * FROM orders
WHERE id = {{rand(1,10000)}}
  AND amount >= {{randf(10,500,2)}};

SELECT * FROM stock WHERE sku = {{pick('SKU1','SKU2')}};
```

占位符只支持数据值，不支持动态表名、列名或 SQL 片段，外层不要加引号。
执行器将模板转为 SQL 和类型化参数，通过 `cursor.execute(sql, params)` 交给 PyMySQL 转义，
不使用 Python `repr()` 拼接 SQL。字符串内的引号、反斜杠、中文由驱动处理。
SQL 本身的 `%`（包括 LIKE、取模和字面量 `%s`）保持原意。

SQL 单/双引号字符串、反引号标识符和注释中的 `{{...}}` 不替换。
例如 `'{{rand(1,10)}}'` 是普通字符串，不是随机数；页面提示外层不要加引号。
生成出来的字符串不会再次解析为占位符。SQL 词法识别按常规 MySQL 引号和反斜杠规则进行。

## 命名变量与作用域

在新建压测页的命名变量配置中，每行填写：

```text
order_id = rand(1,10000)
request_id = uuid()
```

API 的独立配置字段：

```json
{"variables": {"order_id": "rand(1,10000)", "request_id": "uuid()"}}
```

SQL 示例：

```sql
-- weight: 1
BEGIN;
SELECT * FROM orders WHERE id = {{var('order_id')}};
UPDATE orders SET amount = amount + 1 WHERE id = {{var('order_id')}};
COMMIT;
```

- 每次任务执行开始时生成一份变量，同一任务中的所有引用使用同一个值。
- 下次执行重新生成，各虚拟用户互不共享；随机生成不意味着每次值必然不同。
- 任务是一次调度的语句组：无权重时普通语句各成任务、事务块整体成任务；有 `-- weight:` 时整个权重段为一个任务。
- 权重分组没有 BEGIN / COMMIT 时，不具备事务性，但仍可复用变量。
- 普通 `{{rand(...)}}` 等占位符在每条语句执行前独立采样，同样写法的不同位置不共享结果。
- 变量名为 1～64 位字母、数字、下划线，不能以数字开头；变量生成规则不能引用其他变量。
- 配置保存到运行记录，旧记录默认使用空配置。

## 校验与执行

提交时先解析和校验，不执行用户 SQL。未知函数、未闭合占位符、参数数量或类型错误、
非有限数字、倒置范围、空枚举、非法权重、日期错误、字符串长度超限和未定义变量均拒绝启动。
占位符参数错误包含任务编号、语句编号及语句内行列；这不是完整的数据库 SQL 语法检查。

模板在执行进程加载时编译一次，每次请求仅生成参数。请求计时保留任务总耗时口径，包含参数生成和数据库执行。
数据库执行失败仍计入失败指标，并尝试回滚未提交事务，避免残留事务影响后续请求。

随机字符串不保证唯一，写入主键需要业务上保证唯一性。UUID 也不替代数据库唯一约束。
